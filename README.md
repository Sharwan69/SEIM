# SEIM - Security Information and Event Management\n\nA production-ready Node.js SIEM with brute-force detection, suspicious IP monitoring, JWT authentication, and configurable detection rules.\n\n## Features\n\n- **Event Ingestion API** – Collect logs and security events from multiple sources\n- **Brute Force Detection** – Automatically detect repeated failed login attempts\n- **Suspicious IP Monitoring** – Track and manage IPs with malicious activity\n- **Port Scan Detection** – Identify port scanning activities\n- **Anomaly Detection** – Detect unusual patterns and spikes\n- **JWT Authentication** – Secure admin and analyst access\n- **Detection Rules Engine** – Create, manage, and enable/disable security rules\n- **Real-time Alerts** – Socket.IO-powered live dashboard updates\n- **Alert Dashboard** – Monitor security events and incidents\n- **Role-Based Access** – Admin, Analyst, and Viewer roles\n- **MongoDB Integration** – Persistent storage of events and alerts\n\n## Tech Stack\n\n- **Backend**: Node.js, Express.js\n- **Database**: MongoDB + Mongoose\n- **Real-time**: Socket.IO\n- **Auth**: JWT + bcryptjs\n- **Logging**: Winston\n- **Frontend**: Vanilla JS with HTML/CSS\n\n## Getting Started\n\n### Prerequisites\n\n- Node.js 14+\n- MongoDB 4.4+\n- npm or yarn\n\n### Installation\n\n1. Clone the repository:\n```bash\ngit clone https://github.com/Sharwan69/SEIM.git\ncd SEIM\n```\n\n2. Install dependencies:\n```bash\nnpm install\n```\n\n3. Configure environment:\n```bash\ncp .env.example .env\n# Edit .env with your MongoDB URI and JWT secret\n```\n\n4. Start MongoDB:\n```bash\n# On Linux/Mac\nmongod\n\n# Or use Docker\ndocker run -d -p 27017:27017 --name mongodb mongo:latest\n```\n\n5. Start the SIEM server:\n```bash\nnpm run dev\n```\n\n6. Open the dashboard:\n```\nhttp://localhost:5000\n```\n\n## API Endpoints\n\n### Authentication\n\n```bash\n# Register a new user\nPOST /api/auth/register\nBody: { \"username\": \"analyst\", \"email\": \"analyst@seim.com\", \"password\": \"secure123\", \"role\": \"analyst\" }\n\n# Login\nPOST /api/auth/login\nBody: { \"username\": \"analyst\", \"password\": \"secure123\" }\nResponse: { \"success\": true, \"token\": \"jwt_token_here\" }\n\n# Verify token\nGET /api/auth/verify\nHeader: Authorization: Bearer jwt_token_here\n```\n\n### Events\n\n```bash\n# Get all events\nGET /api/events\nHeader: Authorization: Bearer jwt_token_here\n\n# Ingest new event (triggers detection rules)\nPOST /api/events\nBody: {\n  \"source\": \"auth-server-01\",\n  \"sourceType\": \"Linux Server\",\n  \"eventType\": \"login_failed\",\n  \"severity\": \"high\",\n  \"message\": \"Failed login for user admin\"\n}\n```\n\n### Alerts\n\n```bash\n# Get all alerts\nGET /api/alerts\nHeader: Authorization: Bearer jwt_token_here\n\n# Create manual alert\nPOST /api/alerts\nBody: {\n  \"title\": \"Manual Security Alert\",\n  \"severity\": \"high\",\n  \"source\": \"analyst\",\n  \"description\": \"Manual alert created by analyst\"\n}\n```\n\n### Suspicious IPs\n\n```bash\n# Get suspicious IPs\nGET /api/suspicious-ips\nHeader: Authorization: Bearer jwt_token_here\n\n# Block an IP (admin only)\nPOST /api/suspicious-ips/block/192.168.1.100\nHeader: Authorization: Bearer jwt_admin_token\n\n# Unblock an IP (admin only)\nPOST /api/suspicious-ips/unblock/192.168.1.100\nHeader: Authorization: Bearer jwt_admin_token\n```\n\n### Detection Rules\n\n```bash\n# Get all rules\nGET /api/rules\nHeader: Authorization: Bearer jwt_token_here\n\n# Create new rule (admin only)\nPOST /api/rules\nHeader: Authorization: Bearer jwt_admin_token\nBody: {\n  \"name\": \"Custom Detection Rule\",\n  \"description\": \"Detect specific threat pattern\",\n  \"ruleType\": \"custom\",\n  \"severity\": \"high\",\n  \"enabled\": true,\n  \"conditions\": { \"eventType\": \"suspicious_activity\" },\n  \"actions\": [\"alert\", \"log\"]\n}\n\n# Update rule (admin only)\nPUT /api/rules/:id\nHeader: Authorization: Bearer jwt_admin_token\n\n# Delete rule (admin only)\nDELETE /api/rules/:id\nHeader: Authorization: Bearer jwt_admin_token\n```\n\n### Dashboard\n\n```bash\n# Get dashboard metrics\nGET /api/dashboard\nResponse: {\n  \"totalEvents\": 1284,\n  \"criticalAlerts\": 6,\n  \"openIncidents\": 12,\n  \"resolvedToday\": 34,\n  \"bySeverity\": { \"critical\": 6, \"high\": 18, \"medium\": 42, \"low\": 37 }\n}\n```\n\n## Detection Rules\n\nThe SIEM includes built-in detection for:\n\n1. **Brute Force Attacks** – Detects 5+ failed logins in 5 minutes\n2. **Port Scanning** – Alerts on 10+ port scan attempts in 2 minutes\n3. **Suspicious IP Activity** – Tracks IPs with multiple failed attempts\n4. **Malware Signatures** – Detects known malware patterns\n5. **Anomalies** – Identifies unusual event spikes and patterns\n\nAdmins can create custom rules via `/api/rules`.\n\n## Security Features\n\n- ✅ JWT-based authentication\n- ✅ Role-based access control (RBAC)\n- ✅ Brute-force detection with IP blocking\n- ✅ Anomaly detection and alerting\n- ✅ Comprehensive audit logging\n- ✅ Real-time threat notifications\n- ✅ Encrypted password storage (bcryptjs)\n- ✅ Production-ready error handling\n\n## Next Steps\n\n- Add Elasticsearch for high-volume event storage\n- Integrate with Syslog, Windows Event Forwarding, or Linux audit\n- Build a React dashboard for advanced
